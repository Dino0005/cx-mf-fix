# Tested Games

This page lists games that have been tested with CX MF-Fix.

**Legend:**
- ✅ **Working** - Game fully playable with videos/cutscenes
- ⚠️ **Partial** - Game works but with minor issues
- ❌ **Not Working** - Fix doesn't resolve video issues
- 🔄 **Needs Testing** - Reported to work but needs confirmation

---

## How to Contribute

1. Test the game after applying the fix
2. [Open an issue](../../issues/new)
3. Include:
   - Game name and version
   - CrossOver version
   - Status (working/partial/not working)
   - Any notes or issues
